ENIGMA-PD Site Information Request

Thank you for contributing your FreeSurfer data to ENIGMA-PD. This form collects general cohort and MRI acquisition information (regarding the T1w-image) that is used across all ENIGMA-PD projects that make use of this cohort, so that you only need to provide it once rather than separately for each project.

Before you start

  • Think about whether your data represents one or multiple cohorts. If your MRI data were NOT all acquired on the same scanner, with the same sequence parameters and the same software, or if the scanner or protocol changed at any point during data collection, please reach out to us first so we can discuss together which changes warrant splitting your data into multiple cohorts. Once this has been agreed, please fill out this document once per MRI cohort.

How to fill in this form

  • Please complete the yellow cells in the tables below.
  • A grey example column is included in each table to show the expected format of an answer.
  • If a question does not apply to your cohort, please write 'N/A'.
  • Besides filling out this form, we may also ask for some additional subject-level information, if available, such as the interval between MRI and clinical assessment, medication state during MRI and clinical assessment, and use of psychiatric medication. If possible, please share this in a spreadsheet with us over email, or reach out to get a new SURFfilesender link. We appreciate it!

If you have any questions, please do not hesitate to reach out to us at enigma-pd@amsterdamumc.nl. Thank you again for your continued collaboration.
